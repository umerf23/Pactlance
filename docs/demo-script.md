- Product: jointly accepted terms, one active milestone vault, private evidence and deterministic settlement rules.
- Solana role: enforces authorization, sequencing, deadlines and fixed token recipients; the database cannot authorize payouts.
- Validation: insert only recorded test and participant evidence; disclose all remaining gates.
- Links: repository branch, deployed web app if available, demo and public devnet program/mint identifiers.

Use no claims of audit, real-money readiness, guaranteed dispute resolution or measured PKR savings without evidence. Remove secrets and private evidence from recordings.
